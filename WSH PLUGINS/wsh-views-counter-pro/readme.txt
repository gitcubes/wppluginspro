The official PRO extension for WSH Views Counter — unlock advanced analytics, heatmaps, WooCommerce insights, referrer analytics, geo data, viral detection, export tools, multi-post comparison and more.

== Description ==

WSH Views Counter PRO dramatically extends the free **WSH Views Counter** plugin with a full analytics suite designed for publishers, WooCommerce stores, editors, authors, and high-traffic websites.

It uses the same optimized tracking engine from the free version and adds a full dashboard of professional-level analysis modules.

## 🧩 Required Free Plugin

This plugin requires the free **WSH Views Counter** plugin.

---

== Installation ==

1. Install and activate the **WSH Views Counter** free plugin.
2. Upload **wsh-views-counter-pro.zip** to `/wp-content/plugins/`.
3. Activate via **Plugins → Installed Plugins**.
4. Open **Views Counter PRO → License** and activate your license.
5. All PRO modules will appear in the admin menu.

== Frequently Asked Questions ==

= Do I need the free plugin? =  
Yes. PRO extends the free version and relies on its tracking tables.

= Will this slow down my site? =  
No. All analytics queries are indexed and optimized.

= Does this plugin store personal data? =  
No — tracking is anonymous unless IP logging is enabled.

= Does WooCommerce analytics work without WooCommerce? =  
No. WooCommerce must be installed and active.

= Does the plugin filter bots? =  
Yes — improved anti-bot detection is included in PRO.

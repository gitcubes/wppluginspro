## Description

**WSH WooCommerce Bulk Price Manager (FREE)** allows you to update WooCommerce product prices in bulk with full control and maximum safety.

This plugin is built for store owners who want to:

* Change prices for many products at once
* Preview every change before applying it
* Avoid accidental or irreversible price updates
* Keep full control over what gets changed

No risk. No surprises. No accidental price changes.

---

## Key Features (FREE)

✔ Bulk price updates for WooCommerce products
✔ Supports **Simple products** and **Product variations**

✔ Product filters:

* Categories
* Tags
* Attributes (single attribute + value)

✔ Price update methods:

* Percentage increase / decrease
* Fixed amount increase / decrease

✔ Price scope options:

* Regular price only
* Sale price only
* Regular + Sale price

✔ **Preview / Dry Run mode**
See exactly how prices will change before applying.

✔ **Undo last update**
Revert the most recent bulk price change with one click.

✔ CSV Export tools:

* Download CSV template
* Export current target products and prices

✔ Native WooCommerce UI
Uses WooCommerce SelectWoo enhanced dropdowns for a familiar experience.

---

## How It Works

1. Select products using filters (categories, tags, attributes)
2. Choose how prices should be updated (percentage or fixed value)
3. Run **Preview** to review all changes
4. Apply the update
5. Undo the update instantly if needed

---

## Safety First

* Prices are **never changed without confirmation**
* Preview mode shows old and new prices side by side
* Undo snapshot is created before every bulk update
* Invalid or negative prices are automatically prevented

## Limitations of FREE Version

The FREE version is intentionally conservative to keep stores safe:

* Sale prices are updated **only if they already exist**
* Only **one undo snapshot** is stored
* Attribute filtering uses **AND logic only**
* No CSV / Excel import
* No scheduling or automation

## Installation

1. Upload the plugin files to
   `/wp-content/plugins/wsh-woocommerce-bulk-price-manager`
2. Activate the plugin via **Plugins → Installed Plugins**
3. Go to **WooCommerce → Bulk Price Manager**

## Frequently Asked Questions

### Does this plugin change prices immediately?

No. You must first run a preview and then explicitly confirm the update.

### Can I undo a bulk update?

Yes. The FREE version allows undoing the **most recent** bulk update.

### Are variable products supported?

Yes. Product variations are fully supported.

### Will this plugin slow down my store?

No. The plugin uses optimized queries and avoids unnecessary database updates.
